Brief Overview

  • Prerequisite
    • It is assumed that you have gone through previous ramps - first and second ramp.
  • Main Problem
    • In the previous ramp, we have successfully created a gen AI algorithm - A simple AR model.
    • We have seen, it generates novel candidates.
    • But it also generates “non-candidate” \(x\).
    • [mention that we haven’t analyzed why AR sometimes fail to generate.]
    • But without analyzing we can guess what problem it can have.
    • Either it is not creating desired “less-spiky” (talked about this term in previous ramp. Need to come up with better name) distribution which leads to conditions which do not follow 2nd level representation and hence neural network can not generalize. [explain why? Because neural network are having input which are very different than what they are trained on. Distribution of input during training and during evaluation is very different.]

    • Or second reason we could tell that it is creating desired “less-spiky” distribution. Now neural network are still having unseen input but from “training data distribution” [explain in previous ramps, what we mean by this]. This is the case we know and we are expecting neural network to generalize to these cases [mention that this is called “out of distribution” generalization]. But it is not generalizing out of distribution. Which means, it is going to output not so desired “less-spiky” distribution and which is only going to worsen the problem.

    • In AR model, generation process is sequential where trained neural network is used iteratively. So, there are multiple chances where NN can have an input which is not from training data distribution. Initially, the input won’t be far from training data distribution because only one pixel value may be off. Once the NN have this input, it is going to output not-so desired distribution. Which increases the chance of next input being even further from training data distribution than previous input.

    • And this is how AR model is prone to generate non-candidate \(x\). Once it makes error at any point during generation, that error only increases the chance of making more errors. There is a compounding problem where initial error causes even more errors.

    • Compounding problem is there because of conditional probability distribution modeling. Such modeling only care about modeling the local behavior and ignoring its global effect. That is, it do not directly control whole \(x\) but instead just deals with local behavior and just expects that global behavior should come out right.

    • Don’t have control over what \(x\) will have non-zero probability.
      • It means a non-candidate \(x\) can also have non-zero probability.
    • Apart from this problem, AR model has other problems too.
      • [it does not directly learn representation of the data]
      • Also slow in generation because it generates sequentially pixel by pixel.
    • One can think of fixing the AR model’s limitation by having controlled “less-spiky” conditional distributions, instead of uncontrolled “less-spiky” distribution. And somehow tweak a neural network so that it can generalize out of distribution.

    • Let’s follow this trail of thought in some other ramp where we can create an advanced AR model.

    • We can think of one more obvious main problem, which we can deal with in this ramp. Main problem for this ramp is: We want a computer to do “problem-driven imagination” but we need to solve it via a different gen algorithm where we do not have the compounding problem in the first place.
    • Again we can try to solve this main problem for its concrete version where we need a computer to imagine digits in different handwriting.
    • But as mentioned in previous ramp, we want a solution for main problem and not just for its concrete version.
    • [Other option for “main problem” we can have whose solution can be a VAE algorithm is that “we want a model or algorithm which explicitly learn representation of the data”. May be later on, we can replace above main problem with this one.]
  • LS - Model With Conditional Independence
    • Compounding problem is there because whatever pixel value is sampled for a particular pixel affects the probability distribution over values of the next pixel.
    • Probability distribution of a pixel depends on previous pixel values.
    • How do we think of creating a new gen algo where we do not need conditioning in the first place?
    • Why we need conditioning on probability distributions?

    • Because they are dependent.

    • For that, we have to understand what is dependency and why there is dependency?
    • If we know the cause of dependency then may be we can try to remove the cause itself.

    • As we mentioned in previous ramp, cause of dependency is that we don’t know upfront which digit image’s pixel values we are sampling for.

    • In the case of digit gen problem, we can remove dependency only when we know upfront the class, then we can assume conditional independence. And this assumption is weak.
      • It means previous pixel values does not determine what value this pixel should take.
      • Probability distribution of a pixel remains same irrespective of what pixel values chosen previously.
    • [After having above insight, test the insight formally]
      • Test will be successful, i.e. most of pixels will be approximately independent.
      • Few pixels (on edge) are not so independent but they do not matter in terms of preserving the second-level representation. And hence can be used to move the wave randomly and generate novel candidates.
    • [explain why such insight exist]
      • For this we have to understand how this dataset could have come into existence. By looking at its problem-level representations, we can think that how such representation could have come into existence. Someone have decided to allow many people and call them one by one to select a digit randomly (reason for uniform distribution among digits). And write it in approximately same size at the center of a square blackboard with white chalk.
      • As mentioned in previous ramp, class or second-level representation in digit gen problem determine global structure.
    • And we know each class is equally likely.
    • [explain that this let’s model \(T\) in a newer way]
      • We can break \(p(x)\) in a different way where first we need to sample class and then sample each pixel value independently.
    • [now let’s build a gen algorithm with independent pixels per class and test its generation quality]
      • [we will get decent results]
    • By using the second-level representation, we were able to build a model which explicitly take care of the global structure. Which is in contrast to AR model which only models local structure and only indirectly and hence not correctly deals with global structure.
  • LS - Model With Conditional Independence But Without Supervision
    • We are assuming here that we will know labels of each candidate in a dataset.
    • But we want to solve a main-problem and not just its concrete version.
    • [now introduce “supervision” and explain that for many real problems like drug design, the kind of “supervision” we require can be next to impossible]
      • Because it is a manual task.
      • We can label a small unlabeled toy dataset of size like digit dataset.
      • But it is a laborious and hence not practical for large dataset. Not to mention, for real, complex, large datasets, label will be multidimensional because high-level representation will be multidimensional, making labeling even more laborious and difficult. Multidimensional because real world \(x\), e.g. real world image would contain lots of things, hence there will be too much to describe. To imagine such task, imagine labeling every frame of every video on YouTube.
      • And also for many real problems, we might not know what labels to attach to each candidate.
      • For some problems, only domain experts might know how to label but it would be even more time consuming process because there would be only few domain experts.

    • So, most of datasets for real and complex problems are unsupervised.

    • Which means we won’t know class or higher-level representations for each \(x\) in dataset.
      • Not knowing higher-level representations of a \(x\) means not knowing what global structure it has.
    • Having said this, now we want to solve the main problem with unsupervised dataset.
    • So, we should try to solve handwritten digit generation problem again from the beginning but this time we should not be using any labels at all. We should assume that we do not have labels in digit dataset in the first place. Not even in the form of ordering of images in a folder, i.e., all images are randomly shuffled in a folder and not in order where each class images come together.
      • We do not have any information through which we can find labels easily.

    • For unsupervised digit dataset, how we would think of a gen algorithm which does not use conditional probabilities (conditioned on pixel values) at all.

    • When we analyze unsupervised digit dataset:
      • We will still find conditional independence.
      • What class each image corresponds to.
      • And we will find total number of classes.
      • [explain that this is some information about a \(x\) which is not available to us explicitly in the form of labels and it is hidden or latent and only come to our knowledge after manually analyzing it.]
    • So, we know we can build a model without conditional probabilities i.e. by using independent probabilities.
  • LS - Unsupervised Naive Model
    • But without labels, we can’t calculate conditional independent probabilities.
      • We can but it will be a laborious task of manually grouping images class wise.
    • But we know it exists.
    • And after analysis, we can approximately find such probabilities because we will know that all images of each class follows almost same global structure.
      • So, we have to at least pick one image of each class and we can approximately find conditional independent probabilities by assigning dark pixels a probability distribution where probability mass is only over dark pixel values.
      • And similarly assigning bright pixels a probability distribution where probability mass is only over bright pixels.
      • And for this, we can easily manually pick one image of each class in contrast to picking all images of a class manually.
    • Certainly such model is not close to modeling \(T\) perfectly. Because there is no handwriting variations.
    • It means we need to do more work than just picking one image of each class.
      • We can pick more images of each class and calculate probabilities but that would be same as modeling with labeled dataset as we pick more and more images. Because manually grouping images class wise is nothing but labeling them.
    • And since we want to solve the main problem and not just its concrete version, we should assume that grouping images is just laborious or impossible, even if it is not really in handwritten digit problem.
    • So that, we can find an algorithm which really do not use any supervision at all because such algorithm would be useful to solve many real problems where we really do not have labels.
  • LS - Unsupervised Learning and Cost Function
    • Naive model only generates one particular candidate per class.
    • To generate more candidates with different handwriting, we can easily think that pixels surrounding current particular candidate has to have non-zero probabilities.
      • [explain and show with some diagram and experiment by manually giving non-zero probability to surrounding pixels]
    • [Also explain that our model is not flexible. We have “regularized” it by assuming conditional independence. Also explain that this regularization is good enough to only have the kind of higher-level representations we want. It means it can not overfit.]
      • The regularized model if trained on some number of candidates of each class, then it can only generate these candidates and those novel candidates which are “mix” [explain it more] of these same class candidates. But it simply can not generate a non-candidate \(x\).
      • [also explain the term “regularization” if not already explained in previous ramps]
    • Above naive model is trained on one candidate of each class. So it only generate these candidates. And no novel candidates because only one candidate per class is used for training, so there can not be any mixing.
    • For the sake of understanding, let’s train our model on any two images per class. [We will see that only these two candidates per class are being generated and those novel candidates which are mix of these two candidates.]

    • [explain that, by looking more closely at above examples and unsupervised naive model, we understand that training means setting nonzero probabilities to candidates in training dataset in model’s probability distribution.]

    • And if we train our model on more and more candidates per class then it will generate more diverse novel candidates.

    • [may be we can add some of above explanation regarding regularization in the above step where we trained our model with labels]

    • In this sense, “best possible” model is a model which is trained on whole dataset which is same as the model trained by using labels.
      • [explain how it is the best possible model we can get, given the regularization]
      • Why best? Because it is trained on whole training data. So, model has seen all the possible handwriting variations which is available.
      • This makes the model to generate all possible candidates in the dataset and all possible novel candidates by mixing them.
      • Best possible model’s probability distribution and \(T\) is close as possible, given regularization.
    • Above we decided to not manually pick more images per class so how do we train our model on whole dataset?
      • Where training our model means calculating conditional independent probabilities. Which also means setting nonzero probabilities for each training candidates in model’s probability distribution.
    • This looks like a searching problem in real space, similar to what we dealt with in the first ramp.
      • [mention the difference between searching problem in this and first ramp. In first ramp, we searched for weights, here we are searching for probabilities. So, we have to take care of constrain that probabilities need to be between 0 and 1.]
    • Can we do optimization like before?
      • For this, we need a differentiable function whose either minimas or maximas contain the solution - best possible model.

    • This immediately reminds us of KL divergence (explained in second ramp). We can use KL divergence to calculate the difference between model and training data distribution and use this difference as a cost. Minima of this cost means model is as close as possible to training data distribution, which further means model is as close as possible to \(T\).

  • Take Away
    • Mastered various algorithms
      • BMM
      • GMM
      • FA
      • MFA
      • VAE
    • Any model of some \(T\) which is build by only using unlabeled data and assumes some hidden representation is famously called “Latent Variable Model” or in short “LVM”.
    • So, model with multinoulli distribution, BMM, GMM, MFA, VAE etc. are some examples of LVM we mastered from this ramp.
    • It is called such that because “latent variables” are assumed and used to build a model.
      • E.g. in BMM, digit class is latent variable.
      • [explain more about latent variables]
    • [insert this idea some where in ramp]
      • This idea is about “latent” variables. It says that we won’t know these latent variables.
      • In digit gen problem, by manual analysis we were able to understand what are high-level representations and what they represent. But in more real and more complex dataset, understanding these high-level representation and building model which explicitly respects it wont be easy.
      • Therefore, we need some general way to represent global structure which works for all complex datasets.
    • Just like in previous ramp, machine is able to learn to imagine. It means here, we are again doing “machine learning” or we can say our algorithm is “machine learning algorithm”.
      • In this ramp, we tried to come up with the model of \(T\) manually but turns out it is laborious. So, we then thought of letting the computer to find or “learn” the model by itself.
      • This is very similar to first ramp, where we were first trying to hard code the rules for image classification but later on, we let the computer to learn them by itself.
    • Till now, we have seen various ML algorithms.
    • If we look at the differences between these algorithms, we will find several differences.
    • Differences on the basis of dataset - labeled or unlabeled.
      • ML algorithms which uses labeled dataset are called supervised learning algorithms.
        • So, image classification algorithm is a supervised learning algorithm.
      • And the ones which uses unlabeled dataset are called unsupervised learning algorithms.
        • So, algorithms like AR model, BMM, GMM, MFA, VAE etc. which we used for generation problem are unsupervised learning algorithms.
      • These unsupervised learning algorithms can be differentiated further on the basis of type of model. One indirectly finds the probability distribution by using NN, while other (like BMM) directly finds the probability distribution.
